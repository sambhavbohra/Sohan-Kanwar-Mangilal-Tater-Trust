# Sohan Kanwar Mangilal Tater Charitable Trust Website

A freelancing project built for Sohan Kanwar Mangilal Tater Charitable Trust to present their charitable work, impact metrics, gallery, partners, donation details, and contact information in a polished public website.

## Project Overview

This website highlights the trust's work across education, healthcare, community welfare, animal welfare, and infrastructure support. It includes an interactive impact section, project categories, partner/recognition details, and an image gallery using real event and field photos.

## Tech Stack

- React 19
- TanStack Start / TanStack Router
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes

Production-ready gallery assets live in `src/assets`. The temporary local folder `assets to update/` is intentionally ignored and should not be committed to GitHub.
